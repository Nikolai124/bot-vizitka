# Бот-визитка для бизнеса

Telegram-бот, который заменяет небольшому бизнесу сайт-визитку: рассказывает о компании, показывает услуги и цены, отвечает на частые вопросы и принимает заявки. Каждая заявка сразу приходит владельцу в личку.

**Демо:** [@ИМЯ_БОТА](https://t.me/ИМЯ_БОТА)

## Возможности

- Главное меню на inline-кнопках: о компании, услуги и цены, работы, FAQ, контакты
- Навигация без мусора в чате: бот редактирует одно сообщение, а не шлёт новые
- Запись в несколько шагов (FSM): имя → телефон (кнопкой «Отправить мой номер» или вручную) → описание задачи → подтверждение
- Проверка ввода: длина имени, формат телефона, защита от чужого контакта
- Заявка уходит админу со ссылкой «написать», чтобы связаться с клиентом в один клик
- Все тексты вынесены в `content.py`: бот перенастраивается под другого клиента за 10 минут

## Стек

Python 3.12, aiogram 3, aiohttp (вебхук).

## Структура

```
bot-vizitka\
├── bot.py           запуск: polling локально, вебхук на сервере
├── config.py        настройки из переменных окружения
├── content.py       все тексты бота
├── keyboards.py     кнопки
├── handlers\
│   ├── menu.py      меню и разделы
│   └── lead.py      заявка на запись
└── render.yaml      настройки деплоя на Render
```

## Запуск локально

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
# впиши в .env BOT_TOKEN и ADMIN_ID
python bot.py
```

Токен выдаёт [@BotFather](https://t.me/BotFather), свой ID можно узнать у [@userinfobot](https://t.me/userinfobot).

## Деплой на Render

1. Залей проект на GitHub.
2. На [render.com](https://render.com): **New → Blueprint** и выбери репозиторий.
3. Впиши `BOT_TOKEN` и `ADMIN_ID`. `WEBHOOK_SECRET` Render сгенерирует сам.

На сервере бот сам переключается на вебхук: Render передаёт ему свой адрес в `RENDER_EXTERNAL_URL`. На бесплатном тарифе сервис засыпает после 15 минут без запросов, поэтому первый ответ после сна приходит с задержкой до минуты.
